## 6. Cara Menjalankan Notebook

Semua notebook dikerjakan dan dijalankan menggunakan **Google Colaboratory (Colab)**, sesuai arahan perkuliahan.

### Buka di Google Colab (Direkomendasikan)

1. Klik link notebook pada tabel di bagian 3 di atas.
2. Di halaman GitHub, klik tombol **"Open in Colab"** (jika tersedia badge), atau:
   - Salin URL notebook dari GitHub
   - Buka [colab.research.google.com](https://colab.research.google.com)
   - Pilih **File → Open notebook → GitHub**, lalu tempelkan URL-nya
3. Setelah notebook terbuka, jalankan semua sel secara berurutan melalui **Runtime → Run all**.

### Prasyarat

Cukup memiliki akun Google yang aktif — tidak diperlukan instalasi apa pun karena Colab sudah menyediakan semua library yang dibutuhkan secara *pre-installed*.
